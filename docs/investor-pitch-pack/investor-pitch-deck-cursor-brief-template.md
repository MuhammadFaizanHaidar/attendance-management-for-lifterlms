# Cursor Brief Template for Investor Pitch Deck Creation

Use this document as the source prompt when asking Cursor or another model to help generate an investor-style pitch deck.

The better this brief is filled out, the better the deck drafts will be.

---

## 1. Prompting Rules

When using Cursor:
- provide facts first
- separate confirmed facts from assumptions
- ask for multiple options, not one
- ask for investor-grade language, not feature lists
- request challenge/review passes after each draft
- never let the model invent metrics or traction

---

## 2. Master Context Block

Copy and complete this block before prompting:

### Product Name

### One-line Product Description

### Longer Product Description

### Core Problem

### Target Customer

### Buyer/User

### Phase 1 Product Scope

### Phase 2 Product Scope

### Long-term Vision

### Why Now

### Evidence/Traction We Already Have

### Business Model Assumption

### Competitive Alternatives

### Founder/Team Background

### Fundraising Context

### Known Weak Areas or Open Questions

---

## 3. Recommended Prompt Sequence

## Prompt 1 - Positioning Options

Generate 10 investor-quality one-line positioning statements for this company. Make them concise, venture-backable, and focused on business value rather than technical features. Also provide 3 possible product category labels and explain the pros and cons of each.

Attach the completed Master Context Block above.

---

## Prompt 2 - Deck Structure

Using the context below, create:
1. a 10-slide investor deck outline
2. a 12-slide investor deck outline
3. a 14-slide investor deck outline

For each version, explain when it is best used and which narrative strengths it emphasizes.

Attach the completed Master Context Block above.

---

## Prompt 3 - Slide Drafting

Draft slide copy for the chosen investor deck structure.

For each slide provide:
- slide title
- one-sentence takeaway
- 3 bullet points maximum
- what visual or chart should be shown
- what proof is still missing
- short speaker notes

Use concise investor-style wording and avoid generic AI language.

Attach the completed Master Context Block above.

---

## Prompt 4 - Challenge Pass

Act like a skeptical early-stage investor reviewing this deck.

For each slide:
- identify what is weak, generic, unsupported, or unconvincing
- explain what an investor would likely push back on
- rewrite the weakest lines to be sharper and more credible

Attach the current deck draft.

---

## Prompt 5 - Why This Can Be Venture-Scale

Rewrite the market, moat, and roadmap slides so they make a stronger venture-scale argument. Focus on the strategic wedge, data advantage, workflow defensibility, and expansion logic. Do not invent numbers.

Attach the current deck draft.

---

## Prompt 6 - Audience Variants

Create three versions of the same deck narrative:
1. for AI-focused investors
2. for fintech/ops workflow investors
3. for generalist pre-seed investors

Keep the core facts the same but adjust wording and emphasis.

Attach the current deck draft.

---

## Prompt 7 - Q&A Preparation

Generate the 25 toughest investor questions this company is likely to get. Group them into:
- market
- competition
- trust/auditability
- product scope
- GTM
- defensibility
- traction
- team

For each question, provide a concise founder-ready answer and note where the current deck may still be weak.

Attach the completed Master Context Block and current deck draft.

---

## Prompt 8 - Supporting Materials

Using the deck and product context, generate:
- a one-page investor memo
- a short intro email
- a post-meeting follow-up email
- a beta partner outreach message
- a demo script aligned to the deck

Attach the completed Master Context Block and current deck draft.

---

## 4. Review Checklist for Every Cursor Output

Before accepting any output, verify:
- no invented customer names
- no invented numbers
- no unsupported market claims
- no vague AI buzzwords without workflow specificity
- no feature overload
- no contradiction with Phase 1 scope
- no unrealistic business model assumptions

---

## 5. Best Ways to Use Cursor Efficiently

### Use it for
- option generation
- wording compression
- framing alternatives
- skeptical review
- note generation
- audience variants

### Do not use it blindly for
- revenue forecasts
- market size estimates without source logic
- claims about pilots or traction
- legal/compliance statements

---

## 6. Recommended Human-in-the-Loop Process

1. Team fills the brief
2. Cursor generates positioning options
3. Team selects the category angle
4. Cursor drafts deck structure
5. Team edits truth and strategy
6. Cursor sharpens language
7. Team reviews every claim
8. Cursor runs investor challenge pass
9. Team finalizes story and visuals
10. Cursor helps prepare Q&A and follow-up docs

---

## 7. Minimum Document Set to Give Cursor

Before serious deck generation, prepare and attach:
- product roadmap summary
- Phase 1 scope summary
- customer pain notes
- traction/proof worksheet
- founder bios
- pricing assumptions
- any screenshots or workflow diagrams if available

That dramatically improves output quality.
